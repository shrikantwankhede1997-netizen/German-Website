Grammar Guide

At the B2 level, knowing the meaning of a word isn't enough; you must know exactly how it affects the word order of the sentence. Conjunctions in German are divided into four main structural categories.

Rule: Verb gets kicked to the very end!

Hauptsatz + [Conjunction] + Subjekt + ... + Verb.

dass (that) / ob (whether/if)
weil / da (because / since)
obwohl / obgleich (although)
wenn (if/when) / falls (in case)
damit (so that - for purpose)
sodass (so that - for consequence)
indem (by doing... - method)
als ob (as if + Konjunktiv II)
Temporal: nachdem, bevor, während, als, bis, seitdem, solange, sobald

Rule: Position 0 (ADUSO)

These words take up "Position 0". The subject stays in Position 1, and the conjugated verb stays in Position 2.

Aber (but)
Denn (because)
Und (and)
Sondern (but rather)
Oder (or)

Rule: Doppelkonjunktionen

Conjunctions that come in pairs to emphasize connection, alternatives, or contrasts.

entweder ... oder (either ... or)
weder ... noch (neither ... nor)
sowohl ... als auch (both ... and)
nicht nur ... sondern auch (not only ... but also)
zwar ... aber (it's true that ... but)
je ... desto (the [more] ... the [better])

Rule: Konjunktionaladverbien (Verb in Position 2)

These act like conjunctions but are grammatically adverbs. When they start a clause, they take Position 1, forcing the verb directly behind them into Position 2.

deshalb / deswegen / darum / daher
therefore / that's why
trotzdem / dennoch
nevertheless / still
außerdem / zudem
furthermore / besides
